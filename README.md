\# Student Record Management System



\## Project Overview

The Student Record Management System is a C-based application developed to manage student records efficiently using file handling and data structures.



\## Features

\- Add new student records

\- Delete student records

\- Modify existing student details

\- Display student records

\- Store and retrieve student data using file handling

\- Avoid duplicate student records



\## Technologies Used

\- Programming Language: C

\- Data Structures: Linked List

\- Concepts: Pointers, Structures, File Handling

\- Compiler: GCC

\- Version Control: Git and GitHub



\## Project Files

| File | Description |

|---|---|

| `stud\_main.c` | Main program |

| `stud\_add.c` | Add student records |

| `stud\_del.c` | Delete student records |

| `stud\_mod.c` | Modify student records |

| `stud\_print.c` | Display student records |

| `stud\_save.c` | Save student records |

| `header.h` | Header file |

| `make` | Build instructions |



\## Compilation and Execution



Compile the project:



```bash

make

```



Run the executable:



```bash

./a.out

```
